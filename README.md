# Кухни-Мебель СПб — концепт сайта

Готовая статическая сборка для GitHub Pages. Исходники проекта хранятся в приватном
репозитории; здесь публикуются HTML, CSS, JavaScript и изображения без sourcemaps.

Сайт: https://kirill-karpachev.github.io/kitchen-concept-demo/

Источник GitHub Pages: ветка `main`, каталог `/(root)`. Файл `.nojekyll` отключает
обработку Jekyll, чтобы папка `_nuxt` публиковалась вместе с остальными ресурсами.
